# Inkwell

A notebook that writes back, and a map that shows where everyone is.

Write to your diary and an agent answers in ink, then walks off across your pages to do the work. Every page is a place on a living map: zoom out to see the whole notebook, zoom in to read, and watch agents' footprints move between pages as they work. Built on Meta's Muse models.

## Run it

```sh
cp .env.example .env   # add your Meta Model API key
npm install
npm run dev            # http://localhost:5173
```

See `docs/PLAN.md` for the design and architecture.
