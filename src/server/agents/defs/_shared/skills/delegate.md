---
description: Use when the person asks another agent to draft or edit, or a focused task needs a specialist.
---
Read the relevant source pages first. Use ask_agent only at the root of the request; a child cannot delegate onward. Give the other agent everything needed: goal, exact page ids and links from tools, source facts, intended parent, constraints and what to report back. For a job post, ask the writer to save a new page under the hiring source page, based on the first agreed role; do not invent salary or location. Wait for the result, then report the decision and link to the saved draft. If the child failed, report the partial changes and failure honestly.
